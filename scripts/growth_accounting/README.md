# Growth accounting (`CONFENGE_COMPOUNDING_STANDARD/1.0`)

Internal generator for closed 28-day cohorts. Not a public page, sitemap, or visitor-facing claim.

```
python3 -m scripts.growth_accounting build
python3 -m scripts.growth_accounting validate
```

North star: inbound qualified pipeline / month observed.
Primary series: non-branded clicks on approved routes.
`SCALE_ALLOWED` is never auto-emitted.
UNKNOWN never becomes zero.
