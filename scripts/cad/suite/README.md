# Edições de navegador da suíte CAD

Cada entrada de `releases.json` fixa o ZIP de navegador oficial de um aplicativo, seu tamanho e SHA-256. O instalador produz oito ZIPs idênticos aos originais e um índice de leitura em `_site/cad/suite/pacotes/`. O cache externo à árvore do site fica em `~/.cache/confenge-suite-cad/`. O build confere os ZIPs, cada membro e suas licenças. A ferramenta funciona sem contas de terceiros, com os apps no formato em que seus autores permitem redistribuição.

O runtime abre somente membros enumerados no índice de cada release e lê de seu ZIP o intervalo comprimido correspondente. Os bytes são descomprimidos em fluxo. A conferência da release em produção mantém nove ativos físicos adicionais. Os 9.354 arquivos do conjunto de oito ZIPs somam cerca de 1,12 GB. Os membros incluem documentação, licenças e WASM. Diretivas de servidor de terceiros e arquivos ocultos não são executáveis nem endereçáveis pelo endpoint. Cada membro tem ETag correspondente ao conteúdo oficial e o mesmo MIME esperado pelos seus imports relativos.

O Nginx encaminha `/cad/suite/runtime/<app>/` ao runtime existente. Navegação de topo abre a área pública `/cad/aplicativos/#<app>`; iframe e navegação de recursos usam a edição original. O CSP inclui somente os hashes dos blocos executáveis internos e do mapa de imports daquela edição. As conexões de terceiros são bloqueadas. O Service Worker opcional de cada aplicativo mantém seu escopo normal de subpasta. Novas versões exigem atualizar os oito registros, conferir a aplicabilidade do limite de tamanho por membro e repetir testes de abertura e exportação. Antes de trocar a versão, conferir se mudanças no Service Worker afetam os usuários que ativaram a opção offline.

As edições preservam os termos Apache-2.0, os avisos de terceiros e as marcas do fabricante na área interna. A demonstração não representa acesso à nuvem, sincronização de contas, controles físicos do Studio desktop, catálogo remoto de plantas ou licença do SuperCad Studio. A distribuição oficial omite os módulos opcionais de dispositivos do Studio, complementos de conta e sugestões de assistentes. A falha nesses pedidos é tratada pelas próprias edições. Traduções variam entre os apps.

Para validar o transporte, execute `node --test runtime/test/cad-editions.test.mjs`, `npm run test:host-contract` e `npm run host-contract:render`. Para montar os pacotes isoladamente, use `python3 scripts/cad/suite/install.py _site`. Esta rota exige o servidor Node e o encaminhamento pelo Nginx.

Os 74 pacotes de especialidades são a captura conferida de 7/11/2026. Cada `pack.json` preserva o texto original, atribuição e a licença Apache-2.0 explícita. O índice da Confenge deriva desses dados. O fabricante classifica cinco áreas como bem cobertas, 11 como parciais e 58 como iniciais. Os pacotes contêm fórmulas, lições e referências de componentes. Alguns componentes dependem da Library ou de equipamentos externos. `coverage.not_yet` identifica limitações de cada área.

O painel de cálculos carrega os 12 identificadores de `/assets/cad-engines/engines.js` sob demanda. Os módulos oficiais e os 74 pacotes vêm nos dois arquivos compactados deste diretório. As cópias publicadas incluem licença, avisos e endereços oficiais. A lista de 11 motores da página Great Eight é uma descrição editorial. O teste verifica o catálogo executável e um exemplo de cada identificador. Para repetir após a montagem, execute `node tests/cad/suite-content.mjs _site`.
