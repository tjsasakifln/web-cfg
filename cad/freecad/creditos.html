O motor é o FreeCAD 1.1.3 compilado para navegador pela Virtastic, na versão FreeCAD-Web v1.0.9. FreeCAD é marca do projeto FreeCAD, usado aqui para identificar o software. Esta edição não afirma afiliação ou endosso desses projetos.

Código e modificações

O aviso desta distribuição descreve os componentes e as adaptações. A atribuição original e os textos das licenças são preservados localmente. O shell da CONFENGE é publicado em código legível nesta pasta, incluindo inicialização, arquivos, rede, compatibilidade e configuração Python.

Para reconstruir ou modificar o motor, consulte o código-fonte fixado na versão v1.0.9, suas modificações nos componentes e as instruções completas de compilação. Os binários locais mantêm os hashes da publicação original.
